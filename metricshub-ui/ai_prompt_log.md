# Nhật Ký Sử Dụng AI (AI Prompt Log)

### Prompt 1 - Phân tích Flexbox vs CSS Grid
- **Prompt:** "Khi tôi cần một bố cục mà một phần tử con (Child) phải chiếm chính xác 2 hàng và 2 cột (span 2 rows, 2 columns) đan xen với các phần tử nhỏ khác, tôi nên chọn CSS Grid hay Flexbox? Tại sao Flexbox lại chật vật với yêu cầu này?"
- **Kết quả:** Nhận diện được tính chất 2D của CSS Grid, loại bỏ hoàn toàn cấu trúc `div.column` lồng nhau trong Dashboard.

### Prompt 2 - Bootstrap Grid
- **Prompt:** "Trong Bootstrap 5, sự khác biệt giữa lớp col-sm-4 và col-md-4 là gì? Cách dùng hệ thống 12 cột cho Bảng giá Responsive mượt mà nhất?"
- **Kết quả:** Áp dụng `col-12 col-md-4` cho khu vực Bảng giá mà không cần viết tay CSS Media Queries.

### Prompt 3 - Flexbox Navbar Responsive
